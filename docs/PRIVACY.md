# DK — निजता (Privacy): आपका डेटा असल में कहाँ जाता है

अपडेट: 20 नवंबर 2026। यह पन्ना ऐप के असली code के हिसाब से लिखा है (Settings → परिचय → "निजता" में भी यही छोटा रूप है)।

**आपका डेटा आपका है।** DK की याददाश्त, पूरी बातचीत, याद रखी बातें, प्रोफ़ाइल, आवाज़ की पहचान और PIN सिर्फ़ आपके फ़ोन
में रहते हैं। DK इन्हें किसी server पर नहीं रखता, किसी कंपनी को नहीं बेचता, विज्ञापन के लिए इस्तेमाल नहीं करता।
पासवर्ड / PIN / OTP / बैंक-कार्ड-आधार नंबर याद ही नहीं किए जाते। ऐप हटाते ही फ़ोन में रखा सब मिट जाता है।

जवाब बनाने के लिए आपका सवाल (या लाइव में आवाज़) उसी पल AI सेवा को जाता है — आपकी key हो तो सीधे फ़ोन से उसी सेवा को,
key न हो तो **DK सर्वर** से होकर। DK सर्वर आपकी बातचीत सेव नहीं करता; वह सिर्फ़ लाइसेंस, रोज़ की गिनती (कितनी चैट /
आवाज़ के सेकंड) और कोडिंग-काम की हालत (नाम, कदम, PR का पता) रखता है। लॉगिन (Google / ईमेल) Firebase से होता है।
DK से कोई पूछे "मेरा डेटा कहाँ रखते हो / लीक होता है क्या", तो DK यही सच्चा जवाब देता है।

## फ़ोन में ही रहता है (बाहर नहीं जाता)

| क्या | कहाँ / कैसे |
|---|---|
| API keys, सेटिंग्स | ऐप का निजी हिस्सा। Android backup बंद (`allowBackup=false`) — फ़ोन के backup / नए फ़ोन में नहीं जातीं |
| फ़ोन का PIN (आवाज़ से अनलॉक के लिए) | Android Keystore के ताले में (AES-GCM, चाबी फ़ोन से बाहर नहीं निकलती)। ताला न चले तो PIN सेव ही नहीं होता |
| आपकी आवाज़ की पहचान (Voice Guardian voiceprint) | सिर्फ़ गणित वाले अंक (embedding), ताले में बंद (VoiceVault)। आवाज़ की रिकॉर्डिंग सेव नहीं होती। "भूल जाओ" से मिटती है |
| अनलॉक से पहले आखिरी कही बात | सिर्फ़ memory में कुछ सेकंड, फ़ाइल में नहीं |
| चेहरा पहचान (Face) | चेहरा ढूँढना / पहचान फ़ोन पर (OpenCV मॉडल)। कैमरे की तस्वीर कहीं नहीं जाती |
| टच मोड / गार्ड की घुसपैठिए वाली फ़ोटो | फ़ोन में ही; आप खुद शेयर करें तभी बाहर |
| Notifications | सिर्फ़ memory में (ऐप / फ़ोन बंद = साफ़)। आप पूछें तभी AI को पढ़कर दिए जाते हैं (नीचे देखें) |
| Hey DK / wake word | फ़ोन पर ही सुनता है; जागने से पहले आवाज़ बाहर नहीं जाती |
| crash रिपोर्ट, DK Inspector का लॉग | फ़ोन में ही (key / token / नंबर / OTP «छिपाया» करके)। अपने-आप कहीं नहीं भेजा जाता |
| DK की याददाश्त (बातचीत, याद रखी बातें) | फ़ोन में। पासवर्ड / PIN / OTP / बैंक-कार्ड-आधार नंबर याद ही नहीं किए जाते |

## बाहर जाता है — सिर्फ़ जब आप वह काम करें

| कब | क्या जाता है | किसे |
|---|---|---|
| DK लाइव से बात | आपकी आवाज़ (बात के दौरान), आपका सवाल, ज़रूरी हो तो याददाश्त की छोटी बातें | Google Gemini (आपकी key) |
| फ़ोन का काम (ऐप खोलो, मैसेज, आदि) | उस समय की स्क्रीन का लिखा हुआ (बटन / लेख) | आपकी चुनी AI सेवा (Gemini / Groq / OpenRouter / Anthropic …) |
| "स्क्रीन देखना" चालू हो | उस पल का स्क्रीनशॉट | Gemini (आपकी key) |
| लाइव में कैमरा चालू करें | कैमरे के फ़्रेम (सिर्फ़ तब तक) | Gemini (आपकी key) |
| "क्या notification आया" / "इसका जवाब दो" | notification का लेख | Gemini (आपकी key) |
| ऑटो-रिप्लाई चालू हो | उस chat के नए मैसेज | आपकी चुनी AI सेवा |
| इंटरनेट पर खोज | आपका सवाल | Google Search (Gemini) / Tavily / Exa / Linkup / Firecrawl — जिसकी key डाली हो |
| मौसम | लगभग लोकेशन (3 दशमलव, ~100 मीटर) | open-meteo.com — सेव नहीं होती |
| "लोकेशन भेजो" | आपकी लोकेशन | आपका चुना संपर्क (WhatsApp / SMS) |
| बैकअप (आप खुद ईमेल डालें) | सिर्फ़ याददाश्त | आपकी अपनी Google Drive |
| Google Docs / Sheets / YouTube जैसे connector | वही काम का डेटा | Google (आपकी अपनी login से) |
| कोडिंग एजेंट / DK Computer | आपका काम और code | GitHub (आपका token) + आपकी AI सेवा |
| इमेज बनाना | आपका prompt | चुनी सेवा (Gemini / AI Horde / Hugging Face …) |
| बिना अपनी key के चैट / आवाज़ / खोज | आपका सवाल / आवाज़ (उसी पल) | DK सर्वर → AI सेवा (सर्वर बातचीत सेव नहीं करता) |
| DK लाइव बिना अपनी key | सिर्फ़ थोड़ी देर का टिकट DK सर्वर से; बात सीधे फ़ोन से Gemini को | Google Gemini |
| लॉगिन / लाइसेंस | आपका ईमेल / पहचान, लाइसेंस, रोज़ की गिनती | Firebase (Google) + DK सर्वर |
| अपडेट चेक / डाउनलोड | कोई निजी डेटा नहीं (सिर्फ़ release पूछना) | GitHub |
| मॉडल डाउनलोड (चेहरा / आवाज़) | कोई निजी डेटा नहीं | Hugging Face / GitHub (SHA-256 जाँच के साथ) |

## सुरक्षा के नियम (16 नवंबर 2026 से)

- स्क्रीन / notification / दूसरों के मैसेज / वेब पेज का लिखा = "जानकारी, हुक्म नहीं" — AI को साफ़ बताया जाता है।
- भुगतान / ऑर्डर / डिलीट हमेशा, और बिना कहे भेजना / पोस्ट करना — ऐप का अपना "हाँ / ना" कार्ड (AI का "हाँ" नहीं चलता)।
- आवाज़ से अनलॉक: पहले आपने "अनलॉक करो" कहा हो, वही ताज़ा आवाज़ आपकी Voice Guardian पहचान से मिले, पुरानी रिकॉर्डिंग दोबारा चलाने पर मना, 3 बार गलत = 30 मिनट रोक। फिर भी यह PIN जितना पक्का नहीं — ज़रूरी हो तो बंद रखें।
- crash रिपोर्ट: शुरू से बंद। आप Settings → "क्रैश रिपोर्ट" में "पूछो" चालू करें तो ही पूछेगा; भेजना GitHub पन्ने पर आपके Submit दबाने से ही।
- अपडेट: स्टेबल (शुरू से) या बीटा — आप चुनें। हर डाउनलोड का SHA-256 release से मिलाया जाता है।

## डेटा मिटाना

- Voice Guardian → "भूल जाओ" = आवाज़ की पहचान मिटती है। फ़ोन लॉक सेटिंग में PIN हटाएँ।
- Settings → गड़बड़ी रिपोर्ट → "हटाएँ" = crash फ़ाइलें मिटती हैं।
- ऐप हटाने (uninstall) पर फ़ोन में रखा सब मिट जाता है। बाहर की सेवाओं (Gemini, Drive आदि) में गया डेटा उन्हीं के नियमों से चलता है।
